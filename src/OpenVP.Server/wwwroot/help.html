Getting started

Run a program in five steps. Everything below starts from the main page, the Console.

  1. Click a row in Program slots to pick the slot (1–10) you want to use.
  2. Click the file chooser and pick your program: a .cpz or .dll (SIMPL# Pro), a .lpz (compiled SIMPL Windows) or a .smw. For a .lpz, select its .sig too (Ctrl+click) so signals have names. In the desktop app you don't need to: OpenVP finds the .sig next to the program by itself.
  3. Click Load & start. The slot's state turns to Running, and messages from the program appear in the Log.
  4. In the IP table, click a row and then open test panel to press buttons on that IP ID from your browser.
  5. Click Open debugger ↗ to watch the program's signals change live.
Most buttons also show a short description when you hold the mouse over them. Every page has a Help link at the top that opens this page at the right section.

Console (main page)

Load programs, see who is connected, manage the program's files, and read its log. Everything on the page is about the slot selected in Program slots.

Top bar

Metrics ↗
Opens the Metrics page: CPU, memory and how busy each slot is.
Test panel ↗
Opens a blank test panel. Type the IP ID you want and click Connect.
Help
Opens this page.

Status board

A tile
One per slot, across the top of the page, so you can see every slot without clicking into it. A tile shows the slot number and Room ID, the program and its kind (or "empty"), the state (green dot for Running, amber for Stopped, red for Error, dim for empty), how many of the slot's IP IDs have a panel online, and events per second. Click a tile to select that slot, the same as clicking its row below. The selected slot's tile is highlighted. The board refreshes every 2 seconds.
problem
A red badge on a tile. Hover it to read what's wrong. It shows when the slot is in the Error state or when Metrics lists a problem for it: the slot thread stuck in one event, events backing up, a thread left running from an unloaded program, or background work running for 30 s or more.
auto-reload
A blue badge on a tile whose program reloads when its file changes. Hover it to see the file.

Program slots

A row in the table
Click it to select that slot. The rest of the page (IP table, files, console, log) switches to it. The State column shows Running, Stopped, Error or empty.

Slot

Choose files
Picks the program file(s) from your computer. Nothing is loaded until you click Load & start. You can select several files at once, for example a .lpz with its .sig.
Load & start
Uploads the chosen file(s) into the selected slot and starts the program. It replaces whatever was in the slot before. In the desktop app it loads the program from where it is on your computer instead, and brings along the files that belong with it: the .sig with the same name (or the only .sig in that folder), the .lpz behind a .smw, and sidecar files like .openvp.json. The Log lists what came along.
Reload when the file changes
Shown in the desktop app, or when the page is open on the OpenVP computer itself. When ticked, a program loaded from your computer is loaded again by itself whenever its file (or its .sig) changes, for example each time you compile in SIMPL Windows. OpenVP waits until the compiler has finished writing. A running program starts again; a stopped one stays stopped. Your choice is remembered.
Load from path…
Shown when the page is open in a browser on the OpenVP computer itself (a browser can't tell OpenVP where a chosen file is). Type or paste the program's full path, for example C:\Programs\Room\Room.lpz; its .sig and sidecar files come along as above.
Reloads when this changes · Stop watching
Shows which file the slot is watching. Stop watching keeps the program running but stops reloading it. Loading another program, or Unload, also stops it.
Inspect .lpz
Reads the chosen .lpz without running it and prints a report in the Console box: what's in it and which parts OpenVP can and can't run. Add the .sig to see signal names.
Start
Starts the program loaded in this slot, after it was stopped.
Stop
Stops the program but keeps it loaded, so Start runs it again.
Unload
Stops the program and removes it from the slot. The slot becomes empty. Files in NVRAM and User are kept.
Compatibility
Prints a report in the Console box listing anything the loaded program uses that OpenVP doesn't support yet. Check this first if a program misbehaves.
Room ID Edit…
Changes the slot's Room ID (the Virtual Control "room" name). Panels can connect to the slot by this name instead of its number. Shown only when the slot has a Room ID.

IP table

Every IP ID the program registered (touch panels, EISCs and other devices) and who is connected to each.

A row in the table
Click it to open the details below the table: who the client is, how long it has been connected, and traffic counts.
Re-identify
Tries again to work out what the connected device is (its hostname and model), using reverse DNS and Crestron autodiscovery. Takes a few seconds.
Log in & read…
Shows a small login form. Enter the device's SSH username and password, then click Log in & read: OpenVP logs in to the device and reads its hostname, firmware, uptime, network settings and IP table. It only reads; it changes nothing on the device. The password is used once and never saved.
open test panel
Opens a browser test panel already connected to this IP ID and slot.
✕
Closes the details.

Debugger

Open debugger ↗
Opens the Debugger for the selected slot in its own window. Open one per slot to debug several programs side by side.

Files

The folders the program reads and writes, in place of a real processor's storage.

NVRAM User
Switch between the slot's two storage areas: \NVRAM and \USER. The program's own path for the folder you're in is shown on the right.
New folder
Creates a folder inside the one you're looking at.
Upload files
Uploads one or more files into the current folder. You can also drag files or folders onto the list.
Upload folder
Uploads a whole folder with everything inside it.
Folder path (NVRAM / config)
Click any part of the path to go back up to that folder.
📁 A folder name
Click it to open the folder.
⤓
Downloads that file to your computer.
Rename
Gives the file or folder a new name.
✕
Deletes the file, or the folder and everything in it. It asks you to confirm first.
Create … folder / Open …
Appear in a yellow box when the program looked for a file and didn't find it. They create (or open) the exact folder the program expects, so you can upload the missing file into it.

Console

Command box and Run
Sends a console command to the slot, like the text console on a real processor. Type help to list the commands. Pressing Enter does the same as Run.
− +
Make the box shorter or taller. You can also drag its bottom-right corner.
Maximize
Fills the window with the console. Click Restore or press Esc to shrink it back.

Log

The log box
Messages from OpenVP and the program in this slot. Errors are red, warnings yellow, notices blue.
− + Maximize
Same as for the Console box: shorter, taller, fill the window.

Debugger

Shows every signal in the program and its current value on the left, and a running list of changes (the trace) on the right. It works like SIMPL Debugger.

Title bar

Slot list
Switches the debugger to another program slot.
Paths
Opens the Paths view, starting from the signal you have selected.
Console
Goes back to the main page.

Toolbar: recording

● Stream F5
Starts or stops recording signal changes in the trace. Green means recording. The program keeps running either way.
Clear
Empties the trace. Signal values are not affected.
Save…
Saves the trace to a text file on your computer.
Trace: all signals / checked signals only
Chooses what gets recorded: every signal, or only the ones ticked in the T column.
Waveform
Shows or hides a logic-analyzer style chart at the bottom, with one lane for each ticked signal.

Toolbar: stepping

Step mode freezes the program at each signal change so you can see cause and effect one step at a time.

⏸ Step Ctrl+F5
Turns step mode on or off. While it's on, the program pauses at each change until you press Next.
Next ▶| F10
Lets the paused change through and stops at the next one.
◀| Back F7
Shows the step before this one, with values as they were then. It only looks back; the program stays where it is.
Run ▶▶ F8
Turns step mode off and lets the program run normally.
Break on: every change / marked signals ⏸
Chooses what pauses the program: any signal change, or only changes to signals ticked in the ⏸ column.

Toolbar: display

Time
Show trace times as clock time (absolute) or as time since the first row (relative).
Analog
Show analog values as decimal (0–65535), hex or percent.
Serial
Show serial strings as text (ASCII) or as hex bytes.
auto-scroll
Keeps the trace scrolled to the newest row. Untick it to read older rows while new ones arrive.

Signals list (left)

flat tree
Show the signals as one list, or grouped into folders by program structure or name prefix.
Watch-group tabs and +
A watch group is a saved set of signals. Click a tab to show only its signals, or All to show every signal again; click + to make a new group. Right-click a tab to rename it, delete it, empty it, or add the checked or shown signals to it.
Find signal box
Filters the list as you type. Hold the mouse over the ? next to it for the full search syntax (wildcards, by type, by value, exclude).
Type list
Show only Digital, Analog or Serial signals.
Sort list
Sort by name, type, most recently changed or most changes. Clicking a column header sorts too.
checked
Show only signals ticked for tracing.
⏸ marked
Show only signals marked to break on.
active only
Show only signals that have changed since the page loaded or since you last reset activity.
reset activity
Forgets which signals have changed and how often, so "active only" and the Chg counts start again from zero.
✓ all ✗ all
Tick or untick the T box of every signal currently shown.
⊟ ⊞
Collapse or expand every folder (tree view only).
T column
Tick to trace this signal. It's used by "checked signals only" and by the waveform.
⏸ column F9
Tick to pause the program when this signal changes (when Break on is set to marked signals).
Click a signal
Selects it and puts its name in the Force bar.
Double-click a signal
A digital signal toggles between 0 and 1. For an analog or serial signal, the cursor jumps to the Force value box.
Right-click a signal
Opens a menu: set, clear, pulse or toggle it; break on it; check it for trace; add it to a watch group; show what drives it or what it drives; open it in Paths; copy its name.
Drag the bar between the panes
Makes the signals list wider or narrower.

Trace (right)

Filter trace box
Shows only trace rows that match. Same search syntax as Find signal.
follow list
Limits the trace to the signal selected on the left (only selected) or to it and the signals wired to it (selected + neighbours).
this burst only
Click a trace row, then tick this to see only the changes from the same chain reaction (burst).
↳ caused
Shows changes made by program logic in reaction to another change. Untick it to see only outside events: panel presses, device inputs and timers.

Waveform

100 ms 1 s 10 s 1 min
Set how much time the chart shows across its width.
⟳ live
Jumps back to now and follows new changes again, after you scrolled or zoomed.
× next to a signal name
Removes that lane from the chart.
Mouse
Wheel zooms. Drag (or Shift+wheel) moves through time. Click places a marker; double-click removes it. Drag the top edge of the chart to resize it.

Force bar (bottom)

Change a signal by hand, as if the program or a device had done it.

Signal name box
The signal to change. Click one in the list, or type to search.
Value box
The value to set: 1 or 0 for digital; 500, 1F4h or 50% for analog; text for serial (\x0D for a special byte). Pressing Enter does the same as Set.
Set
Sets the signal to the value in the box. With an empty box, a digital signal is set to 1.
Clear
Sets a digital or analog signal to 0, or a serial signal to an empty string.
Pulse
Sets a digital signal high for a moment and then low again, like a quick button press.

Paths

Draws the program's wiring as a map: signals, the symbols between them, and live pulses travelling along the wires as signals change. Use it to answer "what happens when this goes high?" and "why did this change?".

Title bar

Slot list
Switches to another program slot.
← Debugger
Opens the Debugger for the same slot.
Console
Goes back to the main page.

Toolbar

start signal box
Type part of a signal name and pick one. The map is drawn outwards from this signal.
Direction list
What does it drive? → follows the wiring forwards from the start signal. ← What drives it? follows it backwards to find the cause.
Depth slider
How many steps away from the start signal to draw. Lower it if the map is too crowded.
whole program
Draws all of the program's wiring instead of only the part around the start signal.
follow live changes
When something changes outside the part you're looking at, the map moves there automatically.
Fit
Zooms and centres so the whole map fits the window.
Pulse start
Pulses the start signal (like pressing a button) so you can watch the effect travel through the map.
Speed 1× 0.25× 0.1×
Slow motion. At 0.25× or 0.1×, changes are queued and played back slower so you can follow them.
↻ Replay last burst
Plays the most recent chain of changes again.
Skip queue
Drops the changes waiting to be played in slow motion and jumps to what's happening now. Shown only while changes are queued.
Retry
Appears if the wiring could not be loaded. Tries again.

The map

Drag / mouse wheel
Drag to move the map; the wheel (or a two-finger pinch) zooms.
Hover a box
Shows its full name and current value.
Click a signal
Makes it the new start signal.
Double-click a digital signal
Pulses it.
Click +N more
Opens the connections that were folded away to keep the map readable.
Line colours
Grey is a wire, cyan is a signal travelling along it, pink is a loop.

Side lists

Loops & oscillations
Signals that changed more than once in the same chain reaction. Red means it's changing so often it's probably stuck in a loop. Click one to centre the map on it.
Last burst
Every change in the most recent chain reaction, in order. Click one to centre the map on it.

Metrics

A live health check of OpenVP itself: is anything slow, stuck or using too much?

Pause / Resume
Freezes the numbers on screen so you can read them. Resume shows live values again. Nothing in the program is paused.
Console
Goes back to the main page.
show empty slots
Also lists slots that have no program loaded.
The banner at the top
Green when everything is fine. Red with a list when something needs attention, for example a slot that's stuck.
Tiles
CPU, memory, threads, thread pool and uptime of the OpenVP process, each with a small chart of the last few minutes.
Slots table
One row per program: events per second, how busy it is, how many events are waiting, and what it's running right now. Hold the mouse over a column heading for what it measures.
Program threads and background work
Threads and background jobs that programs started, and how long each has been running.

Test panel

A simple touch panel in your browser, for pressing joins and seeing feedback without real hardware.

IP ID
The IP ID to connect as, in hex (for example 03). It must be one the program registered; see the IP table on the main page.
Slot
The program slot to connect to. Leave empty to use whichever slot has that IP ID.
Room
Connect by the slot's Room ID instead of its number. Leave empty if you don't use Room IDs.
Connect
Reconnects using the IP ID, Slot and Room you typed. The dot turns green when connected.
Digital joins 1–20
Press and hold to send that digital join high; let go to send it low. A button turns green when the program sends feedback on that join.
Analog sliders
Drag to send an analog value (0–65535) on that join. The feedback value from the program is shown underneath.
Serial boxes
Type text and press Enter to send it on that serial join. The feedback text from the program is shown underneath.
