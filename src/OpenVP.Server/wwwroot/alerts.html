Channels

A channel is a place to send alerts. Press Test to send a test message and see whether it arrived. Passwords, tokens and webhook addresses are kept in a file only you can read (encrypted for your Windows account on Windows) and are never sent back to this page. Which alerts go to which channel is set under Rules.

Rules

A rule says which alerts go to which channels. An alert goes to every channel named by every rule it matches (once). A rule matches when the alert's kind and slot are listed (empty means all) and it is at least as bad as the rule's minimum severity.
There are no rules, so nothing is sent anywhere. Add one.

Thresholds

A threshold raises an alert when a number stays at or above its warning or critical level for the time you set, and ends it when the number has stayed below for a few seconds. Alerts go out through your rules (kind threshold). The same levels are drawn as dashed lines on the graphs on the Metrics page.
