Console Help

Export processor

One .openvp file with every slot (program files, NVRAM and User files, settings, simulators, integrations, recordings, bookmarks and watches) and the processor settings (integrations, alerts, thresholds, reports, schedules, push targets, recent programs). The access key is never included.

Passwords for email, MQTT, webhook signing secrets, share-link tokens and push-target keys are encrypted (AES-256-GCM, key from your password). Without the password they can't be read, and nobody can recover it for you.

Import processor

Choose an .openvp file to see what is in it first. Nothing changes until you click Import. A snapshot of each slot that is replaced is taken first, so it can be rolled back.

Daily backup

Backs up the whole processor in the export format every day, and keeps them for a number of days. The newest backup is always kept.

Git-backed config

After each change (a program load, settings, files) OpenVP writes a text-friendly copy to a git repository on this computer and commits it, with the Activity entry as the message. Commits are gathered: at most one every 30 seconds. Copied: slot settings, simulators, integrations (secrets removed), watches, the text files in NVRAM and User, the program files, and the alert, integration and schedule settings. Never copied: the access key, saved secrets, share-link and webhook tokens, push-target keys, binary NVRAM files, and any file that has a saved secret in it.

Pushing uses your own git setup (an SSH key or a credential helper). OpenVP never asks for or stores a git password.
