Targets

Other OpenVP servers you can send programs and whole exports to. Each target is its address and its access key or an API token made on that machine (kept in the secret store, never shown again). A programmer token is enough to push a program; a whole export needs admin. It works through the other machine's REST API, so it needs a version of OpenVP with the same API.
