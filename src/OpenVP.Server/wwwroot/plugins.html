Labs Console Help
Plugins is switched off in Labs, so nothing is loaded. An Admin can switch it on in Labs.

A plugin is a folder in data/plugins with a plugin.json, and either a .NET assembly or a small page (or both). Plugins are off until an Admin enables each one here. Look at what a plugin asks for before you enable it.

A plugin is not sandboxed. Its code runs inside OpenVP with all of OpenVP's rights; the permissions below describe what OpenVP's plugin API lets it do, not what the code could do. A plugin that crashes, or doesn't answer in 10 seconds, is unloaded and disabled and OpenVP carries on. Only enable plugins whose source you trust. Plugin pages run inside the console with your permissions.
