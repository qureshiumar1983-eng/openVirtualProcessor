Links

Joins flow both ways between an EISC on this OpenVP and an EISC on another one. This machine opens the connection; the other machine only needs an API token with scope eisc-link (Security, API tokens). It reconnects by itself and sends every join again after a reconnect. Only one side needs a link: the other side's connection shows under Incoming.

How to set one up

  1. On the other OpenVP: switch on Remote EISC in Labs, load a program with an EISC, and make an API token with scope eisc-link (Security, API tokens). Optionally limit it to that EISC's slot.
  2. Here: switch on Remote EISC in Labs, and add the other machine under Push targets with that token as its key. For https with a self-signed certificate, pin its fingerprint there.
  3. Add a link below: this machine's slot and EISC IP ID, the other machine, and its slot and EISC IP ID.

A link joins two EISCs, one on each machine, and what one program sets on its EISC shows up on the other. Two programs that set each other's joins in a loop are slowed down: a serial that just arrived isn't sent straight back, and a join that changes more than 200 times a second is paused for a few seconds.
